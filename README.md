# Task Manager

A Node.js + Express app to add, edit, complete, and delete tasks. Tasks are saved in a JSON file.

## Run it
pnpm install
pnpm dev

Then open http://localhost:3000

## API
- GET /api/tasks
- POST /api/tasks
- PATCH /api/tasks/:id
- DELETE /api/tasks/:id

## Built with
Node.js, Express, HTML, CSS, JavaScript
